USAGE:
   ServiceControl.exe --maintenance

MAINTENANCE

The maintenance switch allows RavenDB Maintenance tasks to be carried out.  In this mode ServiceControl enables the RavenDB Web UI only.
The REST API, message importers and the background document expiry are all disabled.

This mode is only supported when run interactively.

APPLY RETENTION

   ServiceControl.Audit.exe --apply-retention

Applies the configured audit retention period (ServiceControl.Audit/AuditRetentionPeriod) to the messages and saga
snapshots that are already stored. Ingestion sets the expiry of each message from the retention period that is
configured at that moment, so a change of the retention period only affects new messages until this command runs.
The new expiry of each message is its processed time plus the retention period. Messages that are already past the new
expiry are removed by the next expiration run.

Stop the instance before running this command. A persister that applies the retention period when it removes expired
messages needs no update, and the command reports that.

SERVICE INSTALL AND UNINSTALL AND CONFIGURATION OPTIONS

As of Service Control 1.7 the command line  uninstall and install switches have been removed.
Please use the ServiceControl Management Utilities for adding and removing ServiceControl instances.
